# AhaYue Homebrew Tap

```sh
brew install --cask ahayue/tap/tiny-usage
```

[Tiny Usage](https://github.com/AhaYue/tiny-usage) shows Claude and Codex quotas in your macOS menu bar. It requires macOS 14 or later on Apple Silicon.

When a new DMG is published, update the version and SHA-256 in [the cask](Casks/tiny-usage.rb).
